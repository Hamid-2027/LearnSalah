# KiddoVision

A React Native mobile application built with Expo and TypeScript.

## Description

KiddoVision is a cross-platform mobile application template that provides a solid foundation for building React Native applications with modern development practices, including navigation, splash screens, and dark mode support.

## Features

- 🚀 Built with Expo SDK 54
- 📱 React Native 0.81.5
- 🔷 TypeScript support
- 🧭 React Navigation integration
- 🎨 Dark mode UI theme
- ✨ Custom splash screen
- 📦 Organized project structure
- 🔧 Android and iOS platform support

## Prerequisites

Before you begin, ensure you have the following installed:

- Node.js (v14 or higher)
- npm or yarn
- Expo CLI (installed globally or via npx)
- For iOS development: Xcode (macOS only)
- For Android development: Android Studio

## Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd KiddoVision
```

2. Install dependencies:
```bash
npm install
```

## Running the App

### Start the development server:
```bash
npm start
```

### Run on iOS:
```bash
npm run ios
```

### Run on Android:
```bash
npm run android
```

### Run on Web:
```bash
npm run web
```

## Project Structure

- `App.tsx` - Main application component with splash screen logic
- `screens/` - Screen components (Home, Splash)
- `navigation/` - Navigation configuration
- `utils/` - Utility functions and constants
- `assets/` - Image assets and icons

## Technologies Used

- React Native
- Expo
- TypeScript
- React Navigation
- Expo Splash Screen
- Expo Status Bar

## Configuration

The app is configured in `app.json` with settings for:
- App name and version
- Icons and splash screens
- Platform-specific configurations (iOS, Android, Web)
- Dark mode UI theme
